PRIVACY POLICY

How the current browser version of Crimson Ruin handles game information.

Last updated: 20 October 2026

18+ · Mature content: Crimson Ruin includes dark fantasy violence, horror elements and blood-themed magic. This is the creator's content advisory, not an official ratings-board classification.

Game operator

Crimson Ruin is created by MrJim. For game-related questions you can open a public GitHub issue. Do not post sensitive personal information in a public issue.

Gameplay information

Gameplay state, including health, combat, experience, selected powers and run progress, is processed in your browser. The current game does not require registration or an online player account.

Local browser storage

The game uses browser localStorage for some settings and achievements. The currently used keys include crimson-ruin-record-v018 (personal records), crimson-ruin-audio-v06 (audio preferences), crimson-ruin-clarity-v033 (visual clarity) and crimson-ruin-oaths-v033 (Hunter's Oaths). An older audio preference may be migrated from a legacy key. These values remain on the same device/browser unless its site data is cleared; they are not automatically transferred between devices.

Hosting and external resources

The game is hosted by GitHub Pages. GitHub may process network information, such as IP address and browser requests, while delivering the website. See the GitHub Privacy Statement. The game also loads its graphics, audio and scripts from its published site.

Advertising and payments

The current game code does not include third-party advertising or donation checkout services. If the game introduces advertising, analytics or payments in the future, this notice must be reviewed and updated to explain any new providers, tracking and relevant user choices before they are enabled.

Updates and questions

This notice reflects the game's current browser implementation and may be revised as features change. You can review the code in the project repository.
